commitment = a message that tells students to do or attend something by or at a time:
assignment, submission, exam, test, viva, lab record, project milestone, form to fill.
Includes vague ones ("read chapter 4 before next class") and Hinglish ones.

none = everything else: chat, jokes, hypotheticals ("if sir gives a test..."),
things already done ("I submitted yesterday"), requests for notes, forwarded
motivation, birthday wishes, questions with no instruction.

Repeated reminders of the same task each count as a commitment.
When unsure, label it commitment and add the tag "unsure".

error_tags (comma separated): joke, hypothetical, vague, hinglish, forwarded, past_event
