What Makes Study Rescue Different

Study Rescue separates machine learning from deterministic logic for 100% predictable, tamper-proof academic planning.

🤖

Scoped LLM Extraction

Machine learning is used solely to discover candidate task objects and extract raw snippets. It ignores gossip, joke assignments, and false alarms.

⏱️

Deterministic Date Anchor

Language models frequently hallucinate calendar dates. Study Rescue resolves all relative dates (e.g. "tomorrow 5pm", "next Monday") using strict arithmetic against the message timestamp.

📈

Self-Calibrating Overruns

Students regularly underestimate effort. The system tracks actual effort logged against estimates, calculating an individual overrun multiplier.

Deploy the Full FastAPI Backend

The complete backend repository runs on FastAPI, SQLite / Neon Postgres, and Jinja2 templates.

Run Locally in 3 Steps

git clone https://github.com/sayyedkashaf/studyrescue.git
cd studyrescue
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload

Deploy on Render + Neon PostgreSQL

Connect your GitHub repo to Render, set DATABASE_URL pointing to Neon Postgres, set your GEMINI_API_KEY, and launch with build command pip install -r requirements.txt and start command uvicorn app.main:app --host 0.0.0.0 --port $PORT.
